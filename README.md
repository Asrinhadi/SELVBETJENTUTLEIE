# KirkeFlow

Prototype for utleieforespørsler og intern saksbehandling i et kirkelig fellesråd.

Brukeren beskriver arrangementet sitt og får forslag til lokaler med begrunnelse, et forklart prisoverslag og et saksnummer å følge. Saksbehandleren behandler saken i en egen innboks.

## Kom i gang

```bash
npm install
npm run dev
```

Ruter: `/` (veiviser), `/sak/:id` (status for søkeren), `/saksbehandling` (saksbehandlerdemo).

## Avgrensning

Frontend-prototype. Alle data, regler og priser er fiktive. Ingen backend, innlogging eller ekstern lagring — saksbehandlersiden er åpen og er ikke tilgangskontroll.
